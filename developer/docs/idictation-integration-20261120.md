## 请求合同

生产网页和已观察 API 使用 `https://www.idictation.cn` 的 HTTPS 默认 443。没有扫描网络端口。媒体域名和重定向必须从认证响应逐项核验。

主包 519919 的 Axios 配置使用同源 `baseURL:"/"`、50 秒超时、携带 Cookie 和 XSRF 约定；520880 的 wrapper 经产品预处理后发请求，业务结果取 `data.values`。521050/521096 分别为 GET/POST wrapper。普通列表大量使用 POST。

响应 `status == 401` 会引发原站退出；HTTP 468 有额外导航处理。插件应准确记录认证过期和访问限制，停止请求，不自动反复登录或重放写入。

不能按 HTTP 方法判只读：`/api/study/review/v1/clear` 是 GET 清理操作；旧章节 list 带 `is_chapter_finished/is_generate_stories` 时也有写副作用。

独立浏览器的登录操作先勾选协议再提交，记录字段名为 `phone_number/password/api_key/timestamp/nonce/sign`，返回 `status:1,message:"密码不正确"`。用户随后明确指出凭据正确，并重发账号、要求 Chrome、后改为内置浏览器手动登录。以新的成功会话为后续事实源，不把第一次失败归因为用户密码错误。

当前没有实现签名复制、任意 URL 转发、请求混淆、客户端指纹伪装或风控规避。后续传输必须依据站点真实产品流程与当前账号权限；使用相同业务请求不构成“不封号”保证。

## 练习、收藏和进度不能混为一个状态

- 四种练习 mode：听写 1、听音选义 2、默写 3、看词选义 4。
- 普通逐词提交 `/api/study/lexicon/v1/practice/result`，复习提交 `/api/study/review/v1/submit`。字段包括 `lexicon_id,type:success|fail,error_word,key,mode,sence,s_id,source,if_learned`；`sence` 为原拼写。学习计划可能追加 `learning_task_id`。
- `existing_id/last_key` 恢复原站会话；不能用本地 SM-2 次数替代。原站标熟 `proficient` 表示后续听写跳过，也不能映射为本地 easy。
- 收藏按规范化单词文本，经 `/api/study/word/v2/collection` 每 500 词分批，逐词检查 `results[]`。`keep_existing:false` 可能有移动语义，未实测前不假设多书追加。
- 标熟按词条 ID，经 `/api/study/lexicon/v1/label`，`lexicon_ids` 是 JSON 字符串。
- 错词结果外层 `id` 是错误记录 ID，内层 `lexicon.id` 才是练习词 ID。
- 今日复习另有 `pending_words/completed_words/reviewSequenceResult` 和按书 limit=100 的请求；分页、循环答对规则与完成确认都待实测。
