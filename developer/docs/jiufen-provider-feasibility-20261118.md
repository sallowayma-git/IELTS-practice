# 九分学长账号与题源接入 Atlas

2026-11-18 · 安装包 `jiufenxuezhang-ielts-setup-0.9.21-rc.1.exe` · 可行性分析与实施建议

## 【核心判断】

建议把九分学长接成可选题源。用户在 Atlas 设置页连接原账号，看到自己有权访问的目录，点开一套题才加载题面和媒体。Vue 负责作答，Rust 负责联网和数据转换，SQLite 保存本机练习。先用一套阅读走完整条路径，再扩大题型覆盖。

复用原服务能省下账号、内容管理和已有历史的开发。实际仍有三笔工作：把上游题目映射成 Atlas 的答题控件，按服务端策略交付音频和题图，以及将一次远端作答准确对应到本机历史。优先在服务端登记 Atlas 为受支持的客户端，复用现有业务接口。若现有接口只能交付原应用专用的资源包，在九分学长服务端增加一份有版本的题面与媒体清单，让 Atlas 继续走同一条渲染路径。

逐条模拟 `0.9.21-rc.1` 的请求会让插件依赖这版客户端的登录、组卷和资源模式切换细节，服务端升级后需要重新核对。若两端已经共享正式桌面客户端协议和 SDK，直接使用它们即可。若需要请求签名，由服务端为 Atlas 规定凭据、有效期与轮换方式，把长期签名密钥留在服务端。

## 【Linus式方案】实施顺序和验收

1. **用一套阅读确定服务合同。** 从九分学长服务端导出脱敏样本，包括账号权限与运行模式、该账号的目录、一套试题的 Part/Group/Question/Option、提交后的逐题结果和一条历史详情。核实会话生命周期、题目版本、给分规则、接口支持的分页和只读范围。正式接口能交付这些数据就直接复用。如只能交付资源包，先由服务端为 Atlas 提供相同权限下的标准题面导出，再继续。
2. **接可跳过的设置入口。** 设置页增加“题源账号 → 九分学长”。首次启动可以显示可跳过的入口。普通启动直接打开本地库，只有连接题源或主动刷新时才访问九分学长。Rust 通过专用 Tauri 命令管理会话、目录、题面和媒体，长期凭据放现有系统凭据库。账号过期时保留归属明确的本机草稿，重新登录原账号后继续。
3. **打通一套阅读。** 建立 `(题源, 科目, 上游题目或套题 ID) → 本地资产 ID` 映射，为每次练习绑定题目版本或指纹。将上游结构转换成已知的 Atlas 控件和受控标记，按白名单处理富文本、题图与链接。账号可见的目录和已开启的题目单独缓存。首测同时包含一组有显示题号偏移的填空和一组选择题，走通开题、草稿、重启恢复、提交和历史复盘。
4. **明确谁判分，再同步记录。** Atlas 读、听现有提交要求本地存在 `answerKey`。上游若只在交卷后给结果，走官方提交并保存逐题反馈；请求中断时保留待确认状态，按账号和提交标识核对后重试。上游允许本地评分时，用官方样例核对后再启用。既有历史先做远端到本地单向导入，唯一映射用 `(题源, 上游账号 ID, 上游作答 ID)`。同页重拉只产生一条记录，一页的记录和同步位置同事务提交。服务端只有摘要时先显示摘要。题目已更新时只在匹配当时版本后开放题面复盘。
5. **扩大到听力和写作。** 先用一套带地图、两段以上音频的听力验证播放、切节、跳播和链接过期后的恢复；再用一篇带图 Task 1 验证题图和草稿恢复。Rust 从获准的 HTTPS 媒体来源按 ID 取数，对重定向、类型、大小和可用的内容哈希做检查。根据版权与授权策略选择临时缓存或流式交付，长音频测试首播等待和随机定位。WebView 沿用本地媒体入口。最后按使用价值接混合组卷、句级精听、词汇历史、笔记等。

### 不影响既有用户的验收条件

| 场景 | 必须观察到的结果 |
|---|---|
| 未连接、断网、服务维护、登出 | 本地启动、已有题库、写作和历史正常可用。设置页能说明远端状态，用户可以继续本地练习。 |
| 账号 A 切到 B，或账号权限被撤销 | 当前账号只能打开获准内容。A 的草稿、记录、缓存和未确认提交按归属隔离，切回 A 可按策略恢复。撤权后按服务端合同处理媒体和题面缓存。 |
| 远端 ID 撞本地 ID，或上游重新发布同一套题 | 内置题目和既有记录指向原内容。本次练习使用绑定版本，找不到旧版本时保留历史结果并明确提示。 |
| 多选、编号偏移、图面、断网重试 | 题号、答案、逐题给分与同一份官方样例一致。草稿恢复时控件可见。重复同步或重试后本地历史只有一条。 |
| 发布与回滚 | 插件关闭后仍能完成已有的打包练习流程。功能实现后先跑 `python developer/tests/ci/run_static_suite.py`，再跑 `python developer/tests/e2e/suite_practice_flow.py`，补充题源账号切换、资源过期、重复导入的专项用例。 |
