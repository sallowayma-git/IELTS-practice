# 启动、精读与本地数据性能排查（2026-09-30）

本轮已完成代码修复与隔离浏览器验证。原有懒加载确实生效，但分组过大、模块执行时立即初始化、反复读取重型数据，使得“加载了一个界面”同时启动多个功能。此次没有读取或修改真实用户的数据、绑定目录。

## 根因与修复

- **功能捆绑**：`more.bundle.js` 原来包含整套词库、词汇练习、精读和书架。现拆为词汇工具、精读阅读工具、阅读资料库三个按需分组。进入“更多”不会初始化这些模块；从题库、书架、笔记或保存阅读词汇进入相应功能时才加载。书架进入精读也不再顺带加载题库与练习套题。
- **阅读页大词典**：阅读页原来携带 IELTS 词库和 ECDICT。现由首次查词加载，支持并发请求合并、失败重试、子目录、版本参数和发布包路径。阅读页 bundle 从约 6.96 MB 降至 0.99 MB，“更多”从约 1.08 MB 降至 0.079 MB（未压缩）。首次查词约 189 ms，后续约 2 ms。
- **重复全量读取**：精读快照改为读取规范数据，不再为普通读操作加载历史镜像。访问原文只更新阅读状态和书架镜像，不再重写词库；文章标题变化仍同步必要的词汇镜像。原文显示与访问记录确认分开，写入确认之前编辑控件保持禁用，保存异常仍沿用原有处理。
- **嵌套扫描**：词汇归属、出现位置、文章元数据、练习详情合并改用 Map/Set 索引。练习完整投影不再反复读取摘要并逐条查找详情。旧摘要升级结果按持久化修订 epoch 缓存，漏掉跨标签通知、删除记录或摘要变化均会失效；缓存返回副本。
- **大量 DOM**：精读笔记首批只渲染 100 项，再按 100 项加载。搜索和导出仍处理完整数据，不丢失后续项。
- **启动业务竞争**：已完成 V1→V2 迁移的安装不再启动时探测旧 JSON；未完成迁移仍保留，另外保留显式旧数据恢复 API。恢复缓存清理移到空闲阶段。本地备份服务延后初始化，绑定检查不再即时导出整个数据库，未绑定时不启动写盘轮询。

## 本地文件与数据保护

浏览器 IndexedDB 是在线编辑的数据源；**应用内备份**仍在浏览器中，不能独立抵御浏览器存储清除。**绑定文件夹的 JSON**是浏览器外的恢复副本，只有授权并通过写后校验才能认为已保存。

- 已绑定目录按 3 天间隔提醒保存，显示独立 JSON 的含义。后台只查询权限，不主动弹浏览器授权；用户点击保存才请求权限。提醒仅在可见概览/更多界面且无其他对话框时显示，避免干扰练习。
- 提醒时间与最后成功写盘时间独立；提醒不标记数据已备份。权限失效、写入失败保留脏状态。已有备份绑定、恢复预览、恢复前安全快照、原子提交、跨标签写锁、重置阻断、写后验证继续保留。
- 新增安装内数据库身份，独立于可移植快照。浏览器数据库重建但目录绑定仍在时，禁止自动或普通手动写入，要求先恢复；恢复成功后才采用新身份。测试验证阻断期间原文件字节不变，以及恢复后可继续写盘。
- 身份保护从升级后首次成功保存或验证一致快照开始生效。历史绑定此前未记录身份时，无法仅凭缺失标记可靠判断旧数据库是否被清除。本轮没有证明全部历史丢失反馈均被解决，也不删除旧迁移来源。

## 剩余瓶颈

5,000 词精读首次显示约 1.8 秒，访问记录保存和校验完成仍约 6 秒；5,000 条练习页再次打开约 2.9 秒，全量 JSON 导出约 3.4 秒。大快照校验、序列化及部分面板计算仍在主线程；“异步 Promise”本身不会把 CPU 工作移出主线程。后续需要在保持事务与校验语义的前提下，将纯计算移至 Worker，或进一步按文档/文章缩小读取与计算范围。本次保留准确的剩余耗时，未用降低数据校验强度换取速度。
