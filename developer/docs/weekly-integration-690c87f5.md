the isolated `F:/workspace/IELTS Atlas integration` worktree. The original

## Data compatibility

- Migration 0034 adds the reading display-tag index and retains `soul_revisions`
  for historical audit. No Soul model writer or edit/undo command is reactivated.
- Before upgrading, the migrator validates the divergent 31-33 history and its
  identifying columns. Unknown names, gaps and mixed local/remote histories are
  refused. Recognized local history is copied, including original timestamps,
  to `migration_meta.weekly_snapshot.original_migrations`.
- The bridge then applies remote 31-33 and replaces their ledger entries in one
  transaction. Profile columns, complete matching skills and remote cleanup are
  therefore present even on a previously upgraded snapshot database. Failure
  rolls back the whole bridge. Existing on-disk databases use the normal verified
  pre-migration snapshot before any structural changes.
- Backup format 21 includes both context snapshots and Soul audit. The snapshot
  family of format 19 is identified by its Soul table, question-kinds column,
  absent context tables and absent coach profile column; the remote family
  retains its own required tables. Unknown combinations remain invalid.
- Remote old backups without question-kinds columns rebuild that derived index
  within the restore transaction. Packages that already carry the column retain
  their original cells, preserving lossless current-format round trips.
- Historical prose JSON stays untouched in `weekly_digests`. The read-only
  `weekly_history_list` command feeds Notebook's weekly shelf: a legacy digest
  becomes a prose-only card in its own window, deduplicated by week so a typed
  report always wins. There is no separate 历史周记 block. Stored fact
  references render as escaped plain text. Typed reports continue to use
  `weekly_report_list/current`; prose is never treated as a typed report.

## Ported features

- Reading library display tags/index/backfill. Display tags use the target's
  scoring classifier, including word-bank summary completion and neutral matching.
- Unified navigation, dashboard, library cards, writing topic picker, history
  cards, settings data tools, design system v3 and notebook art/mascots.
- Weekly cards and a detail sheet consume typed reports. Card labels use stable
  ISO week identifiers instead of a sequence that changes when list limits move.
- Dev-only browser mock, filtered to registered commands and updated for typed
  reports, preferences, reading archives and durable coach feedback. Unknown
  commands fail explicitly. Production builds do not inject it.

Remote draft safety and the renamed `Atlas Noto Serif SC` font are preserved.
`exam-frozen.css`, root exam tokens, target font definitions and all tracked exam
baselines remain unchanged.

## Deliberately separate product increments

Snapshot free-form weekly generation, fact-placeholder repair preflight, Soul
editing/model revisions and alternate daily-baseline statistics are not restored.
Their persisted historical data is retained, but activating those features would
require a separate product change. No retired prompt-skill, retrieval or teaching
strategy implementation/test is revived.
