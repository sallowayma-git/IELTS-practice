### 在线联调

Atlas 已在 `www.9fnnn.com` 直接取到这篇阅读。线上正文、题号和选项与 `03` 一致。账号接口的客户端合同来自 `0.9.21-rc.1`。

| 操作 | 已确认的客户端行为 |
|---|---|
| `POST /user-auth/v1/email-code/send` | JSON 含 `email` 和 `purpose: "login"`，请求头带安装标识 `X-XXGG-Client-Id`。成功后使用 `cooldownSeconds`，缺省 60 秒。Atlas 生成自己的安装标识。 |
| `POST /user-auth/v1/email-code/login` | JSON 含 `email` 和六位字符串 `code`。凭据和稳定账号标识取自成功响应。后续已登录请求使用 `token` 请求头。 |
| `POST /user-auth/v1/session/renew` | 发送 `{}`，超时为 10 秒，续期响应必须仍属当前账号。已认证调用遇 HTTP 401/403 或业务码 401、403、10401、10403 时要求重新登录。服务端签发时长待确认。 |

在同一设置页的「九分学长账号」输入测试邮箱和验证码。会话只驻留在 Atlas 本次进程。点击「提交并核对测试阅读」会使用线上题目 ID 发送一次交卷，Q1 选 `A`，Q13 提交空字符串。这个按钮写入当前在线账号的正式练习历史。

成功后面板展示脱敏请求、回执中实际采用的 ID 字段和官方逐题得分。若需要证据文件，可复制「脱敏交卷与复盘样例」中的 JSON。插件只在回执、账号、题目和 13 条作答全部匹配后导入 Atlas 历史。若收不到可识别的回执，设置页给出 `clientSubmissionId` 供服务端核对。已有回执时再次点击只查询复盘。
